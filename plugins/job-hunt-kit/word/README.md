# Word template

`jobcv-template.docx` sets the look of the Word CV and cover letter. `cv-tailor` never edits
Word documents by hand. It writes the tailored content to `content.json`, and
`skills/cv-tailor/scripts/render.py` builds fresh `.docx` files from it using the styles in
this template. The text in the template is only a style sample; every build replaces it.

## Changing the look

1. Copy `jobcv-template.docx` into your workspace as `templates/jobcv-template.docx`.
2. Open it in Word (or LibreOffice) and change the **styles**, not the text: Home → Styles →
   right-click a style → Modify. Fonts, sizes, colours, spacing, borders and page margins are
   all yours to change.
3. **Keep the style names.** The renderer looks styles up by name. A style you delete is
   recreated with the default look.
4. Save. The next build uses your copy.

| Style | Used for |
|---|---|
| `CV Name`, `CV Title`, `CV Contact` | the header block (body text, not the page header) |
| `CV Section` | section headings (all caps, navy rule below) |
| `CV Body`, `CV Inline`, `CV Skill` | paragraphs, `·`-separated lines, skill groups |
| `CV Role`, `CV Org` | job title; organisation line with right-aligned dates |
| `CV Bullet` | bullets (based on Word's `List Bullet`) |
| `CV Degree`, `CV Institution` | education |
| `CV Running` | page 2+ running head and page numbers |
| `CL Date`, `CL Recipient`, `CL Subject`, `CL Salutation`, `CL Body`, `CL Closing`, `CL Name`, `CL Signature` | cover letter |
| `CV Label`, `CV Dates`, `CV Link` | character styles: skill labels, dates, links |

The page size comes from `documents.paper` in `job-hunt.yaml`; margins come from the template.

## ATS rules this layout keeps (please keep them too)

- **One column.** No text boxes, no layout tables, no columns. Many ATS parsers read text boxes
  and table cells out of order, or not at all.
- **Contact details in the body**, not in Word's page header, which some parsers skip.
- **Real text everywhere**: headings are styled text (capitals come from the style's All Caps
  setting, so the underlying word stays "Education"), separators are characters, and there are no
  icons.
- **Standard fonts.** Calibri is the default because it's on every Word install, and LibreOffice
  substitutes the metric-compatible Carlito, so the page count stays the same.

## Page count

A `.docx` has no fixed page count until something lays it out. `build.py` converts each file to
PDF with Microsoft Word (Windows, via COM), docx2pdf, or LibreOffice, whichever it finds, and
checks the PDF's page count against the budget. With none installed, the `.docx` is still
written and the build says `pages NOT checked`.

The template is generated by `python render.py --make-template word/jobcv-template.docx`.
Regenerate it after changing the default styles in `render.py`.
